From tic-tac-toe to gomoku

Where does each game-playing AI fall apart as the board gets bigger?

In 1961 Donald Michie taught about 300 matchboxes to play tic-tac-toe. Gomoku is the same game on a 15×15 board, where a matchbox per position would need more boxes than there are atoms in the universe. mnk-bench measures exactly where that approach, and every other kind of game AI, breaks down, and why.

What is an m,n,k game?

Two players take turns placing stones on an m×n board, and the first to get k in a row wins. Tic-tac-toe is (3,3,3) and gomoku is (15,15,5). With gravity, stones drop to the bottom of their column, so Connect Four is (6,7,4)+gravity. One engine covers all of them, so the same agents can be measured on every board.

Bigger boards spread the ratings out

On tic-tac-toe every competent agent draws the others, so the ratings bunch up between 1,418 (MENACE) and 1,525. On (6,6,4) depth-4 alpha-beta went 240–0 and the trained tables lost to everything except random.

On Connect Four a 39k-parameter network trained only by self-play, for 10 minutes on one CPU core, is level with alpha-beta and beats the rule-based player 40–0. The same network trained on (3,3,3) and (4,4,4) never loses to perfect play.
